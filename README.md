# TempRoot-KSU-repo
Curated repository of modules compatible with Temporary Root environments (temporary KernelSU/Magisk).

## How to Add

1. Copy the repository URL:
   ```text
   [https://raw.githubusercontent.com/winterballs/TempRoot-KSU-repo/refs/heads/main/modules.json](https://raw.githubusercontent.com/winterballs/TempRoot-KSU-repo/refs/heads/main/modules.json)

2. Open KernelSU and go to Settings (gear icon).
​3. Select Repositories (or Module Repositories).
​4. Tap the + button, paste the copied URL into the input field, and save.
​5. Return to the Modules tab and refresh the list.
